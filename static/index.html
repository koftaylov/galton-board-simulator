Help

Simulation

Drop balls through a Galton board and watch the distribution form in bars or buckets.

  • Balls: total balls per run, up to 1,000,000.
  • Levels: peg rows, from 1 to 20.
  • Runs: repeats the same setup and can save stats between runs.
  • Right bias: chance that each normal peg sends the ball right.

Motion

  • Speed: changes animation pacing.
  • Simple: steady segment timing.
  • Gravity: uses the Feel preset for heavier or bouncier movement.
  • Simulate in background: keeps simulation time catching up when the tab is not focused.

Launch Modes

  • One: next ball starts after the previous one finishes.
  • lvl2/lvl5: next ball starts after the current ball reaches that level.
  • Aval: launches balls in a stream.
  • All: launches all balls at once.
  • No vis: calculates results without animating balls.

Wildcards

  • + adds wildcards after click on its type. - removes matching wildcards. Off clears all peg states.
  • Click on Types modifies state of some random pegs.
  • Clicking a peg cycles it through the wildcard types and back to Normal.
  • Mirror reverses the chosen direction.
  • Magnet pulls toward the center.
  • Repeller pushes away from center.
  • Bumper jumps across the same row. Auto placement always leaves some non-Bumper pegs in each row.
  • Teleport disappears and reappears at any peg.
  • Splitter creates an extra ball.
  • Sticky makes the next bounce weaker.
  • Chaos ignores bias.
  • Random adds random state.

Display And Sound

  • Show paths saves trails for visible balls.
  • Color turns colors balls by left/right turns.
  • Ghost overlay shows the expected binomial curve.
  • Bar stats, Line stats, Label stats compare saved runs.
  • Sound controls bounce/turn audio. Sounds and Effects control wildcard feedback.

Limitations

  • Only visible balls animate; very large runs are batch-calculated for responsiveness.
  • Changing peg states while balls are moving refreshes each active ball's remaining route from its next peg.
  • Random wildcard placement skips the top row. Sticky also skips the last row.
  • Manual peg clicks can set any peg type and are preserved from random add/remove operations.
